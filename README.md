# ThinkAble

Aplikasi media pembelajaran Berpikir Komputasional (*Computational Thinking* / CT) inklusif dan ramah anak (Jenjang SD, SMP, SMA).

## Fitur Utama
- **Filosofi Bebas Tekanan:** Tanpa skor, tanpa peringkat, tanpa nyawa, tanpa timer, dan tanpa warna merah.
- **4 Pilar Berpikir Komputasional:** Dekomposisi, Pola, Abstraksi, Algoritma.
- **Peta Petualangan 20 Langkah:** Petualangan berbasis cerita per modul ajar.
- **Alur Cerita Sinematik:** Format percakapan 2 maskot bergaya *RPG Cutscene* sebelum tantangan soal terbuka.
- **Mesin Evaluasi 2-Tahap:** Respon ramah anak dengan petunjuk bertahap tanpa hukuman.
- **Aksesibilitas Lengkap:** Pilihan ukuran teks (A / A+ / A++), Mode Tenang, Kontras Tinggi, dan Haptic/Getar.
- **Rasio Lanskap Terkunci:** Desain 800×360 px dengan *contain scaling*.

## File Utama
- `thinkable.html`: Prototipe interaktif mandiri (*self-contained*).
- `PRD ThinkAble Prototipe HTML Interaktif.md`: Dokumen persyaratan produk (PRD v2.0).
- `rules.md`: Aturan keras desain (*Design Rules*).
- `task.md`: Daftar tugas dan pelacak kemajuan.
- `user-flow (1).md`: Diagram alur navigasi dan mesin evaluasi.
